# Каталог расчетов

## Введение
В процессе работы у меня накопилось множество инженерных калькуляторов: файлы Excel, ссылки на сторонние сайты и небольшие portable - программы. Многие из них дублировали друг друга, отличаясь лишь степенью проработки и удобством использования. Также со временем подобных инструментов в интернете становилось всё больше - их активно создавали и выкладывать как энтузиасты, так и крупные компании.

В какой-то момент мне захотелось собрать коллекцию расчетов в каталог: упорядочить, добавить поиск, систему рейтингов и справочные материалы. Причём запустить проект именно в виде веб-приложения или сайта чтобы иметь к нему доступ с любого компьютера или телефона. Так пришла идея сделать сайт в виде заметок - отдельных карточек с наименование расчета, кратким описанием и ключевыми словами для быстрого поиска.

Поскольку я не программист, воплотить идею в жизнь мне помогает ИИ - он пишет код и даёт пошаговые инструкции по моим запросам.

---

## Описание
Каталог представляет собой сайт с карточками - ссылками на сторонние ресурсы с инженерными калькуляторами, реализована система поиска по  ключевым словам.
Проект разработан на чистом JavaScript.

 **[Открыть сайт](https://ylapenko.github.io/calclib/)**

---

## Ключевые возможности

*   **Единый интерфейс:** Все необходимые калькуляторы собраны в одном месте с удобным каталогом.
*   **Динамическая фильтрация:** Быстрый поиск нужного расчетного модуля с помощью системы фильтров и мгновенного сброса параметров.
*   **Ночной режим:** Поддержка темной темы оформления (переключатель 🌙 в шапке сайта) для комфортной работы в любое время суток.
*   **Полная адаптивность:** Интерфейс корректно отображается как на экранах стационарных компьютеров, так и на смартфонах.

## Стек технологий

*   **Язык программирования:** Чистый JavaScript (Vanilla JS, ES6+)
*   **Разметка и стили:** HTML5, CSS3 (использование кастомных CSS-переменных для переключения тем)
*   **Хостинг:** GitHub Pages (автоматическое развертывание)
